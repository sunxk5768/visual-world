# 视界 · Visual World

视界是一款用于对比网页视频和图片的浏览器扩展。点击扩展图标，即可在独立标签页中选择素材、同步播放和逐帧查看。适合比较同一镜头的不同生成结果，也可以把参考图和视频放在一起，检查构图、色彩和细节。

## 对比模式

| 模式 | 用法 |
| --- | --- |
| 并排 | 同时查看多份素材，可拖动卡片调整顺序。 |
| 交替 | 在同一位置切换素材，观察切换前后的变化。 |
| 透明度 | 叠加画面并调整透明度，检查轮廓和构图偏移。 |
| 滑动对比 | 拖动分界线，对照两份素材的局部细节。 |

## 安装

1. 在仓库页面点击 **Code → Download ZIP**，解压下载的文件。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的文件夹。

如需从本地 HTML 页面抓取素材，请在扩展详情中开启「允许访问文件网址」。

## 使用

1. 打开包含视频或图片的网页，点击工具栏中的「视界」图标。
2. 在预览页选择要对比的素材。视频和图片可以混选。
3. 选择对比模式。查看视频时，可同步播放、调整倍速，或拖动时间轴定位到指定帧。
4. 来源页更换素材后，点击「重抓」更新列表。

## 默认快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 上一帧 / 下一帧 |
| `Home` | 回到起点 |
| `1` / `2` / `3` / `4` | 并排 / 交替 / 透明度 / 滑动对比 |
| `C` | 切换 A/B |
| `Z` | 复位缩放 |

点击预览页的齿轮按钮可以修改快捷键。
